### Research

#### UROP: Machine Learning Analysis of Iceland's Groundfish Survey
*Undergraduate Research Opportunities Program · Spring 2026*

I worked on a research project using data from Iceland's spring groundfish survey (SMB), focusing on catch data for cod, haddock, redfish, and wolffish.

I preprocessed the data and trained several machine learning models, including Ridge regression, Random Forest, and gradient boosting. I compared their performance using spatial-block and leave-one-year-out cross-validation to evaluate how well the models generalized across locations and years.

The project also explored how environmental conditions, fishing gear, and location contributed to variations in fish catches.
